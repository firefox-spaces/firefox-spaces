Hide Firefox’s tab bar

The Spaces sidebar replaces the row of tabs at the top of the window. Firefox doesn’t let extensions hide that row, so it takes a small style file that you add once. It takes about two minutes, and you can undo it at any time.

  1. Allow custom styles

    Type about:config in the address bar and press Enter. Accept the warning, search for the setting below, and double-click it so it reads true.

  2. Add the style file

    Type about:support in the address bar. Next to Profile Folder, click Open Folder.

    Finder opens the folder around your profile, with your profile folder highlighted (its name ends in something like .default-release). Double-click that highlighted folder to go inside it first. A chrome folder made one level up is ignored.

    Inside your profile folder, create a folder named chrome (all lowercase), if there isn’t one already. Put the file userChrome.css inside it:

    Saved to your Downloads folder. Move it into the chrome folder. If you already have a userChrome.css there, paste the CSS at the end of it instead of replacing it.

What the file hides

        
    
          
  • The tab bar at the top of the window. The sidebar replaces it.
    • 
          
  • The title bar above the sidebar, the strip with a name and a ✕. Firefox draws it over
            every sidebar and extensions can’t remove it — and the old sidebar sometimes shows another extension’s
            name, such as Bitwarden, while the Spaces sidebar is open. Firefox’s current sidebar (Firefox 136 and
            newer) uses a new header element that doesn’t say which panel it belongs to, so the file hides it on
            every panel there — Bookmarks and History lose their label and ✕ too, but the sidebar’s own
            controls still close them. On the old sidebar (sidebar.revamp set to false) only extension
            sidebars are affected and Bookmarks and History keep their header.
    • 
          
  • The profile label in the address bar. Each space keeps its own cookies and logins in a
            Firefox container, and Firefox normally shows that container’s name and color at the right end of the
            address bar. The space’s name and color already tell you where you are, so it’s hidden.
    • 
        

        
If you add this file by hand, check that all three parts are in it, and that the title-bar rule
          lists both #sidebar-header and #sidebar-panel-header — an older copy only has the
          first, which current Firefox ignores, leaving the title bar visible.


        
Still seeing the tab bar after restarting?

        
    
          
  • Check the setting in step 1 reads true.
    • 
          
  • The chrome folder must be inside your profile folder, the one listed next to
            Profile Folder in about:support, not next to it.
    • 
          
  • The file must be named exactly userChrome.css, not userChrome.css.txt or
            userChrome.rtf. Text editors sometimes add an extension you can’t see.
    • 
          
  • Quit Firefox completely (Firefox → Quit on macOS), not just close the window.
    • 
        


        
Good to know

        
    
          
  • Leave Firefox’s own vertical tabs turned off (Settings → General → Browser Layout). This file hides the horizontal tab bar only.
    • 
          
  • To undo it, delete userChrome.css from the chrome folder and restart Firefox.
    • 
          
  • You can reopen this page from the Spaces sidebar: ⚙ Settings → Hide Firefox’s tab bar.
